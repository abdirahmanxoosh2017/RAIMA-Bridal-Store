# RAIMA Bridal Store

## Complete Bridal E-Commerce & Wedding Planning Management System

**Brand:** RAIMA BRIDAL STORE  
**Tagline:** Elegance for Your Special Day

This repository implements the complete RAIMA Bridal Store system represented by the approved UI specification:

- 20 Customer Panel pages
- 20 Admin Panel pages
- Authentication and role-based authorization
- Product, category, dress, accessory and service management
- Shopping cart and checkout
- Orders and order tracking
- Wedding planning and booking management
- Payments, reviews and wishlist
- Coupons and discounts
- CMS pages and banners/sliders
- Newsletter
- Reports, settings and activity logs

## Technology

- PHP 8+
- MySQL 8+
- HTML5 / CSS3
- JavaScript
- Bootstrap 5
- PDO with prepared statements
- Session-based authentication

The implementation should be production-oriented, responsive, secure, maintainable, and faithful to the provided RAIMA visual design. Every page should be connected to real database-backed functionality rather than static mockups.
